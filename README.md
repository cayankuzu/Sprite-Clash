# Sprite Clash

`intermediate_py` klasöründeki Pygame sınıf, kalıtım, sprite group ve
`groupcollide` örneklerini oynanabilir bir tarayıcı oyununda birleştirir.

- Beş koridordan şövalye göndererek yaklaşan canavarları durdur
- Masaüstünde 1–5 tuşları veya tıklama
- Mobil/tablette koridora dokunma ya da büyük kontrol tuşları
- Responsive canvas; dikey ve yatay ekran desteği

Özgün ders kaynakları `intermediate_py` klasöründe korunmuştur.
